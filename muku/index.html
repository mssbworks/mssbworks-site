muku Restaurant Tools for long life

見本のお店「つばめカフェ」の7月の締めを、ムクと一緒に見ていく動画です（2分37秒）。つばめカフェは見本用に作ったお店で、実在しません。

飲食店のレジのジャーナルを読んで、数字の検算と分析をし、店との対話を通して論点を整理する道具です。Claudeに「コネクタ（MCP）」としてつないで使います。

買って終わりではなく、使うほど店の事情を覚えて読みが深くなる。育てるコンサルです。

使えるお店

読めるレジ
Airレジとでん票くんです。ほかのレジのお店は、買う前にお問い合わせください。
要るもの
Claude（Anthropic社のAI）のアカウントです。月次の巻は、Claudeの無料プランのチャットで始められます。

巻の並び

月次の巻販売中
レジのデータから毎月の売上を検算し、要点と問いかけをExcelにまとめます。予算の組み立ても入っています。
原価の巻準備中
レシピ・原価・仕入を1つにまとめます。毎月の納品書から食材の単価を新しくして、理論原価率を出します。Claude Code で使います。

買える場所

  • note
  • Brain

noteとBrain、どちらで買っても中身は同じです。月次の巻 980円（税込）。

お預かりするもの

お店の売上・商品名・お客様の情報は、当社のサーバーを通りません。計算はお店で使っているClaudeの中で済み、結果はお店のExcelに残ります。

当社が預かるのは、ムクの鍵の発行に使うメールアドレスなどです。全部の項目はプライバシーポリシーに書いています。

作っている会社

株式会社ムササビ（代表 渡部龍哉）は、飲食店のコンサルティングの会社です。商品開発・オペレーション・購買・人の仕組みづくりを、お店と一緒にやっています。

ムクは、顧問先のお店で毎月やっている、レジの数字の検算と月次のまとめから作りました。
